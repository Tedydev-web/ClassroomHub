**SSO**, **token auth**, and no-tracking mode are built into this self-owned distribution. The API
does not call an external license service, and `LICENSE_KEY` is not required.

## Feature docs

- [Enterprise SSO](/enterprise-sso) — Single Sign-On with OIDC (Okta, Azure AD, and more).
- [Token Auth](/token-auth) — issue signed tokens to log users in from your own app.
