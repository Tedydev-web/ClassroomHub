You're here to build something on top of ClassroomHub, not run an academy in it: calling the API
from your own app, connecting an agent client or an SSO-style handoff, or working on
ClassroomHub's own code.

<CodeGroup>

```bash cURL
curl https://api.classroomio.com/public-api/v1/courses \
  -H "Authorization: Bearer cio_api_your_key_here"
```

```js JavaScript
const res = await fetch('https://api.classroomio.com/public-api/v1/courses', {
  headers: { Authorization: 'Bearer cio_api_your_key_here' }
});
const { data } = await res.json();
```

</CodeGroup>

Full endpoint reference, request/response schemas, and how to get a key: [API](https://classroom.io.vn/docs/api).
